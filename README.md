# Retro Arena

Онлайн-мультиплеер для классических игр Sega Mega Drive и NES (Dendy) прямо в браузере, на компьютере и на телефоне. Первая игра — **Ultimate Mortal Kombat 3**.

## Как это работает

```
 Игрок 1 (хозяин комнаты)                         Игрок 2 (гость)
 ┌──────────────────────────┐   WebRTC: видео+звук   ┌──────────────────────┐
 │ EmulatorJS (Genesis Plus │ ─────────────────────▶ │ <video>              │
 │ GX) запускает ROM        │ ◀───────────────────── │ кнопки / стик /      │
 │ ввод P1 + ввод P2        │   WebRTC: нажатия      │ клавиатура / геймпад │
 └──────────┬───────────────┘                        └──────────┬───────────┘
            │          WebSocket: комнаты и сигналинг          │
            └──────────────────▶  Node.js-сервер  ◀─────────────┘
```

- Эмулятор работает **только у хозяина комнаты**. Второй игрок получает видеопоток (как при демонстрации экрана) и отправляет нажатия кнопок. Поэтому не нужно синхронизировать два эмулятора, и рассинхронизации не бывает.
- Сервер почти ничего не делает: создаёт комнаты, передаёт сообщения для установки WebRTC-соединения и раздаёт ROM. Сама игра идёт напрямую между игроками.
- Задержка у хозяина нулевая. У гостя к ней добавляется время передачи по сети, обычно 30–100 мс в пределах одного города.

## Возможности

- Комнаты с кодом из 4 символов и ссылкой-приглашением `/r/ABCD`.
- Режимы: онлайн-бой, игра в одиночку, вдвоём за одним ПК.
- **Телефон:** плавающий стик (появляется под пальцем), кнопки как в аркадном MK (`HP BLK HK` / `LP RUN LK`), можно вести палец по кнопкам, работает в портретной и горизонтальной ориентации, настраиваются размер и прозрачность кнопок.
- **Спецприёмы одной кнопкой:** игрок выбирает своего бойца, и появляются кнопки его приёмов. «Вперёд» и «назад» определяются автоматически по координатам бойцов в памяти игры, поэтому приёмы работают с любой стороны.
- **ПК:** клавиатура и геймпады (Xbox/PS/любые стандартные).
- Фильтры картинки: сглаживание HQ, эффект ЭЛТ-телевизора, чёткие пиксели. Картинка растягивается на весь экран в пропорции 4:3.
- PWA: игру можно добавить на главный экран телефона.

## Управление

| | ПК (один игрок / онлайн) | Вдвоём за ПК: игрок 1 | Вдвоём за ПК: игрок 2 |
|---|---|---|---|
| Движение | стрелки или WASD | WASD | стрелки |
| HP · BLK · HK | U · I · O | R · T · Y | Numpad 4 5 6 (или K L ;) |
| LP · RUN · LK | J · K · L | F · G · H | Numpad 1 2 3 (или , . /) |
| Start | Enter | 1 | Enter |
| Спецприёмы | 1 – 4 | — | — |

Кнопки UMK3 (6-кнопочный джойстик Sega, проверено в меню игры *6 Button Joy Config*): X — HI PUNCH, A — LO PUNCH, Z — HI KICK, C — LO KICK, B — BLOCK, Y — RUN.

## Запуск

Нужен Node.js 18+.

```bash
npm install
# ROM не входит в репозиторий. Положите его в roms/ под именем из games.json:
node tools/smd2bin.js "Ultimate_Mortal_Kombat_3.smd" roms/umk3.bin   # .smd → .bin
npm start            # http://localhost:8080
```

Через Docker:

```bash
docker compose up -d --build     # ROM-ы берутся из ./roms
```

### Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `8080` | порт сервера |
| `ROMS_DIR` | `./roms` | папка с ROM-ами |
| `GAMES_FILE` | `./games.json` | каталог игр |
| `EJS_DATA_PATH` | CDN EmulatorJS 4.x | откуда браузер грузит эмулятор (можно разместить у себя) |
| `STUN_URLS` | Google STUN | STUN-серверы через запятую |
| `TURN_URLS`, `TURN_USERNAME`, `TURN_PASSWORD` | — | TURN-сервер |

**TURN для мобильного интернета.** Если оба игрока сидят за строгим NAT (часто бывает у мобильных операторов), прямое соединение не установится, и интерфейс покажет «нужен TURN-сервер». В `docker-compose.yml` есть закомментированный coturn: раскомментируйте его и пропишите `TURN_*`.

**HTTPS обязателен для продакшена.** На телефонах WebRTC, полноэкранный режим и PWA работают только по HTTPS. Поставьте перед сервером nginx или Caddy с сертификатом и проксируйте WebSocket `/ws`.

## Как добавить игру

1. Положите ROM в `roms/`.
2. Добавьте запись в `games.json`:

```json
{
  "id": "contra",
  "title": "Contra",
  "subtitle": "NES · 1988",
  "system": "nes",
  "core": "fceumm",
  "rom": "contra.nes",
  "players": 2,
  "controls": "nes"
}
```

Поддерживаемые схемы управления (`controls`): `genesis6`, `genesis3`, `nes`. Новые схемы описываются в `public/js/schemes.js`. Необязательные поля:

- `layout` — свои подписи и расположение кнопок на экране;
- `hint` — подсказка в настройках;
- `specials` — спецприёмы для каждого бойца: шаги через запятую, одновременные нажатия через `+`. `F`/`B` означают «вперёд/назад», `U`/`D` — вверх/вниз, кнопки называются по подписям из `layout`;
- `facing` — адреса X-координат игроков в RAM, чтобы определять, куда смотрит боец.

## Структура

```
server/index.js      HTTP + WebSocket, /api/config, раздача ROM
server/rooms.js      комнаты и пересылка сообщений
public/js/app.js     экраны и режимы (одиночный, вдвоём, хост, гость)
public/js/emulator.js обёртка EmulatorJS, перехват звука для трансляции
public/js/net.js     WebRTC: HostLink / GuestLink
public/js/input.js   клавиатура + геймпады → битовая маска
public/js/touch.js   экранные стик, кнопки, спецприёмы
public/js/macros.js  проигрывание спецприёмов по кадрам
public/js/ram.js     чтение RAM Mega Drive из памяти эмулятора
games.json           каталог игр
tools/smd2bin.js     конвертер .smd → .bin
```

## Ограничения

- Пока хозяин комнаты играет, его вкладка должна быть активной: если свернуть браузер, игра встанет на паузу.
- Список спецприёмов в `games.json` составлен по памяти и проверен не для всех бойцов. Если приём не срабатывает, поправьте его последовательность в `games.json`.
- ROM-ы защищены авторским правом и в репозиторий не входят. Прежде чем открывать доступ публично, убедитесь, что у вас есть права на распространение игры.
